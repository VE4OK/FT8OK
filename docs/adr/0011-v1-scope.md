# 0011 v1 scope: FT8 only, Map and occupancy in, FT4 and POTA profile deferred
**Status:** Accepted (2026-10-12). Sets the v1 mode scope and definition of done. **Context:** v1 has to be small enough to finish and good enough to use daily. The maintainer named the Map tab and the occupancy strip with automatic TX-frequency picking as must-haves, and did not pick FT4 or the POTA/SOTA activation profile. **Decision:** v1 = core RX/TX/QSO/log/time-sync + Map tab + occupancy strip with auto TX-frequency picking, **FT8 only**. FT4 and the POTA/SOTA activation profile (activation profile, per-park ADIF naming, P2P reference entry) are deferred to the first release after v1. **Consequences:** The `Mode` abstraction (ADR 0006) is still built in v1 and FT4's constants stay defined and JVM-unit-tested, so FT4 is a later switch-on, not a rewrite; no FT8 constants may leak out of `Mode` regardless. (FT4 late-start value) leaves the v1 critical path. The ADIF writer and the verified POTA field mapping (ADR 0008 amendment) still ship in v1 — only the profile that populates `MY_SIG_INFO` waits, so a v1 activation log would carry no park reference and pota.app's uploader would prompt for it. v1 is therefore a **home-station-first** release despite the portable premise in; revisit immediately if the first real outing is an activation. The Map being in v1 makes the bundled Natural Earth outline a v1 asset (~782 KB for the 50 m Admin-0 layer, verified).

**Amended 2026-10-21:** sending DXpedition (0.1) messages is in v1. In a CQ run, our RR73 to one station and the next waiting caller's report go out as one transmission, by default and with no setting. It is one signal at full power, never multi-stream Fox mode. Receiving them was already built.

**Amended 2026-11-02:** receiving every message type WSJT-X shows is in v1: ARRL Field Day, RTTY Roundup, EU VHF contest and WSPR-in-FT8 are decoded, shown, and their senders heard in Roster and Map. They are never answered. Sending contest exchanges (a contest mode under CQ ⋯) is not in v1 until planned and agreed.

**Amended 2026-11-02:** contest mode is in v1: set in Settings › Contest, not under CQ ⋯. It covers our CQ, answering callers, S&P and the CALL tab, and survives a restart. Field Day and the grid contests (NA VHF, WW Digi, ARRL Digi) are built first; RTTY Roundup and EU VHF follow in that order. The receive-only line of the amendment above holds only while contest mode is off.

**Amended 2026-11-12:** FT4 ships as a separate app, **FT4OK** (`com.ft4ok`), built from the same code as the `ft4` product flavor of `:app`, with its own settings and logbook. FT8OK stays FT8 only, so neither app has a mode switch. See [FT4OK](../technical/12-ft4ok.md).
