# 0003 Foreground-only operation, no notifications
**Status:** Accepted. **Context:** Background microphone use on Android requires a foreground service and a persistent notification; the user wants no notifications and the screen on, dimmed. **Decision:** Operate only while visible. On background or screen lock: stop capture and hard-disarm TX. In-app cues only (visual, optional haptic); no app sounds because audio goes to the radio's USB codec. **Consequences:** No `FOREGROUND_SERVICE*` permissions, mic only live while on screen. Dimming uses window brightness (the test phone has an LCD, not OLED).
