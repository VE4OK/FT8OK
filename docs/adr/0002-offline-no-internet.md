# 0002 Fully offline, no INTERNET permission
**Status:** Accepted. **Context:** The audit of the older apps found network and privacy issues, and v1 needs no online feature. **Decision:** v1 ships with only `RECORD_AUDIO`. A CI/lint check fails the build if the merged manifest contains `INTERNET` (libraries can add it silently). **Consequences:** No PSKReporter, spots, online tiles, uploads or update checker. Time comes from the OS clock, band consensus, or manual offset. Logs leave via the share sheet or files. A future online flavour stays possible behind an empty `network` boundary and a `SpotSource` interface.
