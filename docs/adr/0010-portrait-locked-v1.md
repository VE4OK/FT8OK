# 0010 Portrait-locked v1, landscape not designed out
**Status:** Accepted (2026-10-12). **Context:** The app targets one-handed portable SOTA/POTA use, so portrait is the only layout v1 actually needs; a home-station layout on a propped-up phone or tablet was left open in. Supporting both now roughly doubles the layout and test surface and adds rotation state handling to every screen, for a use case that does not exist yet. **Decision:** Lock the manifest to portrait for v1. Keep every layout metric a named design token and make no hard-coded screen-size or aspect assumptions, so adding a landscape or tablet layout later is a change, not a rewrite. **Consequences:** One layout to build, test and tune for direct sunlight; rotation-state bugs cannot occur in v1. The instrumented-test item for rotation becomes "orientation stays locked". Revisit on the maintainer's request, most likely when a home/desktop-style layout is wanted.
